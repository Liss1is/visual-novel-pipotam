# Visual Novel

## Идея проекта
Визуальная новелла в жанре хоррор. Действие происходит в глухом лесу, где главному герою (смотрителю вышки) предстоит столкнуться с пугающими событиями. Игроку предстоит принимать решения, влияющие на развитие сюжета, атмосферу и судьбу персонажей, чтобы прийти к одной из концовок.

## Планируемый стек и инструменты
* **Движок:** Ren'Py 8.5.3 (на базе Python 3).
* **Среда разработки:** Ren'Py Launcher.
* **Контроль версий:** Git + GitHub.
* **Графика и дизайн:** Ручная отрисовка спрайтов и фонов в графических редакторах.
* **Аудио:** Поиск и подбор бесплатных ассетов (музыка, звуковые эффекты) для создания атмосферы.
* **ИИ-ассистенты:** Используются доступные модели как консультанты для генерации идей, правок, ревью кода и поиска ошибок.

## Архитектура проекта
Проект использует стандартную структуру Ren'Py, модифицированную под наши задачи.
* `game/script.rpy` — основной файл сценария, содержащий линейные диалоги и ветвления (меню выборов).
* `game/screens.rpy` — файл интерфейса (главное меню, экраны настроек, UI выборов).
* `game/images/` — папка с фонами (bg) и спрайтами персонажей (sprites).
* `game/audio/` — звуковые эффекты (SFX) и музыкальное сопровождение.
* `docs/` — проектная документация (состав команды, планы).

## Статус проекта
На данный момент проект находится в активной стадии разработки. Исходный код и ресурсы обновляются на регулярной основе.

## Сборка и запуск
По завершении разработки будет собран готовый билд игры, который будет прикреплен к разделу **Releases** на GitHub. 
Для проверки исходного кода в текущем виде вы можете клонировать репозиторий и открыть папку проекта через Ren'Py Launcher (SDK версии 8.5.3).
